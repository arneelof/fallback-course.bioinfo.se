References

Every page of this book names its sources where it uses them. This chapter collects them in one place: first the open textbooks and resources the book is built on, then all papers and books cited on any page (checked against PubMed or CrossRef), then databases, datasets and software, and finally the further reading and watching suggested for each session. “Cited in” links back to the pages that use each source.

The open sources this book is built on

This book draws its narrative content from fully open sources, supplemented by original writing. None of the sources below restrict commercial use. Every page names which of them it used.

  • Dive into Deep Learning. Zhang, A., Lipton, Z. C., Li, M., & Smola, A. J. https://d2l.ai. CC BY-SA 4.0. Primary source for every machine-learning session. Adapted material from this source is, per that license, shared here under the same terms.
  • Wikipedia. https://en.wikipedia.org. CC BY-SA 4.0. Conceptual and algorithmic depth for the bioinformatics sessions, and occasional historical notes elsewhere. Never assigned as reading directly, but synthesized into this book’s own bounded pages (see the Welcome page for why).
  • EMBL-EBI Training. https://www.ebi.ac.uk/training/. CC BY 4.0. The practical, tool-use layer for databases and sequence alignment.
  • bibook. Käll, L. https://github.com/statisticalbiotechnology/bibook. CC BY 4.0. Notebook code implementing classical bioinformatics algorithms (pairwise alignment, MSA, and more), adapted with attribution.
  • NCBI Bookshelf. https://www.ncbi.nlm.nih.gov/books/. Public domain (US government work). The BLAST algorithm and database practicalities, including the BLAST® Help manual.
  • RCSB PDB-101. https://pdb101.rcsb.org/. CC BY 4.0 (the PDB-101 educational tier; general rcsb.org article text is separately copyrighted and is not used here).
  • A Byte of Python. Swaroop, C. H. https://python.swaroopch.com/. CC BY-SA 4.0. Python fundamentals and object-oriented programming.
