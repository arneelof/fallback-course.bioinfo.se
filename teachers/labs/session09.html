Question 4 · choose all that apply · 1 point

Why is cross-entropy the better choice for a classifier? (More than one answer can be correct.)

  • It punishes a confident wrong answer (probability near 0 on the true class) very strongly, because −log p grows without bound as p approaches 0

  • Its gradient does not vanish when the softmax output is badly wrong, whereas MSE and MAE on saturated probabilities give only small gradients

  • It is the only loss that PyTorch can differentiate

  • It makes the network have fewer parameters

Question 8 · choose all that apply · 1 point

Which explanations of your Section 5 results are reasonable? (More than one answer can be correct.)

  • Momentum steps along an average of recent gradients, so directions that agree from batch to batch add up and noisy ones cancel: it gets further than plain SGD in the same number of epochs

  • Adam also averages gradients (like momentum), and in addition divides each weight’s step by a running average of the size of its gradients, so it adapts the step size separately for every weight

  • The ranking holds for these 10 epochs and these learning rates; with more epochs or a better-tuned learning rate, plain SGD could catch up

  • Adam and momentum compute more accurate gradients than plain SGD

  • Plain SGD would beat the others if its learning rate were increased without limit

  • The linear model wins: with far fewer images than weights a hidden layer cannot help

  • The hidden layer pays off, but modestly (a few percentage points): pixels combine in non-additive ways, so a hidden layer helps even with fewer examples than weights. “Examples per weight” is a warning sign, not a strict rule
