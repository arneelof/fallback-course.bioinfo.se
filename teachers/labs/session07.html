The real dataset

The notebook fetches 55 real proteins live from EBI’s PDBe API (the same API as the Session 7 page’s HBB example), or uses a cached copy of the same values if the API is not reachable. For each protein: its amino-acid composition (20 features) and its alpha-helix fraction (the target to predict), across a range of folds from almost no helix to mostly helix.

Question 2 · choose one · 1 point

Why does the notebook test both models on a held-out 25% of the proteins, rather than on the same data they were fit on?

  • Held-out data trains faster than the full dataset

  • Testing on data not used for fitting gives an estimate of how well the model generalizes to new examples, rather than how well it memorized the training data

  • It’s required by scikit-learn’s API

  • Held-out data always gives a lower error than training data

Two models, the same data

Linear regression and a small, from-scratch multilayer perceptron (one hidden layer, tanh, plain gradient descent, in the same style as the XOR notebook’s hidden-layer model), both fit on the training proteins and both tested on the same held-out ones.
