Session 3: Biological Databases

Three-hour lab · revised 27 November 2026

Students investigate human myoglobin (MB) through ten required tasks. They find and connect records, export different sequences, examine annotation evidence, compare structural records and trace a reported interaction to its experiment. Each investigation ends with one graded single-answer or multiple-answer question.

Download the current lab notebook · Read the notebook · Preview all ten graded questions without answers

Open the downloaded notebook in VS Code or upload it to Colab. The Colab badge opens the published copy, which may lag behind local revisions. Students edit the indicated parameters and paste sequence exports; they do not write retrieval code from scratch. The notebook displays source data and supports their interpretation.

The ten questions are worth one point each; five points meets the existing pass threshold. All ten tasks are required. Students submit the quiz and the separate feedback survey through the Session 3 Canvas module. Canvas lists the deadline.

Suggested schedule

The previous version was completed in about one hour in the feedback received. This revision adds independent record selection and comparisons. The budgets below are planning estimates for 150 minutes of investigation plus 30 minutes for setup, a break and submission. They are not measured completion times. Pilot the revised lab with students of different experience levels, separating time spent investigating from delays caused by unavailable websites.

Teaching and service notes

  • Keep the sequence-retrieval and validation code working. The added workload comes from record selection, comparison and interpretation.
  • Task 3 normally uses the UCSC transcript-detail export controls. An explicitly labelled official API route reconstructs the same sequences if export is unavailable; students record which route they used.
  • For Tasks 6–7, PDBj is a verified alternative interface to the same PDB records if RCSB is unavailable. The three experimental comparison records are instructor-selected; they are not all cross-references from the human protein entry.
  • Task 7 tests source organism and experimental construct, not resolution, prediction confidence or structural alignment. Do not require the older construct-mutation question or full-paper methods reading.
  • Task 9 retains the evidence-evaluation objective. The pair-specific interaction record, publication abstract and short assay explanation are sufficient; students do not need the full paper.
  • Use the answer markup in labs/session03-databases.text2qti.md for grading review. The web preview contains no answer key. Record changes in live databases and use the course's existing discrepancy policy.
