Session 3: Biological Databases

Three-hour lab

Build a small dossier for human myoglobin (MB). Compare sequence records in a notebook, locate the gene in a genome browser, then trace a protein annotation, a structure and a reported interaction to their evidence. Keep the record links, versions and dates as you go so that someone else can repeat your checks.

Download the lab notebook · Preview all ten graded questions

Open the notebook in VS Code or upload it to Colab. Complete the graded quiz and feedback survey in the Session 3 Canvas module. The quiz contains ten automatically graded questions. Choose one answer when prompted, or select all correct answers for questions that allow more than one. Each question is worth one point. Five points meets the pass threshold. Canvas lists the deadline.
