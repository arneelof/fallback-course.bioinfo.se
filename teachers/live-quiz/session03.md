# Session 3: Biological Databases (short lecture quiz)

## 1. You find the same HBB accession and sequence through NCBI and ENA. What have you found?

mode: once

- [ ] Two independent experiments confirming the annotation
- [x] Two access routes to one shared archival record
- [ ] Two different genes with the same name
- [ ] Proof that every annotation in the record is correct

## 2. You report the exact HBB mRNA sequence used in an analysis. Which identifier includes its sequence version?

mode: once

- [ ] HBB
- [x] NM_000518.5
- [ ] 3043
- [ ] NP_000509.1

## 3. A reviewed UniProt entry contains a claim about a protein's function. How should you assess its support?

mode: once

- [ ] Assume every claim in a reviewed entry has been demonstrated experimentally
- [ ] Reject the claim unless a 3D structure is available
- [x] Check the evidence attached to that claim and its linked references
- [ ] Use the entry's review date as the measure of experimental support

## 4. You need genomic DNA, a transcript and its encoded protein for HBB. What is the main advantage of a genome browser?

mode: once

- [x] It connects these biological levels through views within one resource
- [ ] It guarantees that every annotation has experimental support
- [ ] It gives the gene, transcript and protein the same identifier
- [ ] It removes the need to choose an organism, assembly or transcript

## 5. An old paper's Trace Archive link no longer opens. What should you do next?

mode: once

- [ ] Conclude that the underlying data have been deleted
- [ ] Replace the accession with the first search result for the gene name
- [x] Keep the accession, consult the provider's current access guidance and check the retrieved record's metadata
- [ ] Count the same accession at a new website as a separate experiment

## 6. Two human transcript records have different transcript identifiers. What is the best check that they originate from the same gene?

mode: once

- [x] They link to the same gene identifier within the same database and annotation release
- [ ] Their transcript identifiers have the same prefix
- [ ] Their sequences both use T instead of U
- [ ] Their transcript sequences have the same length

## 7. A non-coding RNA sequence record is displayed with T instead of U. What does this mean?

mode: once

- [ ] The sequence must come from a protein-coding gene
- [ ] The record must describe genomic DNA
- [ ] The record proves that a physical cDNA sample was made
- [x] The database uses the DNA alphabet to represent the RNA sequence

## 8. You find an HBB transcript sequence record. What else do you need to estimate HBB RNA abundance in a blood sample?

mode: once

- [ ] Only the length of the transcript sequence
- [x] Expression measurements from the relevant sample or condition
- [ ] The same sequence displayed at a second archive website
- [ ] Only a predicted structure of the encoded protein
